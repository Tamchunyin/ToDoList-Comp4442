# Project Name
## ToDoList
This Project is ToDoList System. Demo with a light system with register and login system, also include perform the normal function.  

## Project Requirement
Program language: Java version: JDK 17  
Development Framework：Spring boot version: 4.0.6  
Database: AWS RDS MYSQL  
EC-2 instance (For public access)  

## Usage
For the spring boot, we use environment variable in application.properties.  
Please setting EDS path, Database Username, Database Password in your environment.
